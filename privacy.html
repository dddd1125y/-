개인정보 및 쿠키 안내

시행일: 2026년 10월 17일 · 리셀리(Reselly)

이 안내는 리셀리 웹 도구가 작동하는 방식과 현재 데이터 저장 방법을 설명합니다. 외부 플랫폼인 GitHub Pages에서 사이트가 제공되므로 해당 플랫폼의 데이터 처리에는 GitHub의 정책도 적용됩니다.

1. 리셀리 입력 데이터

상품명, 매입가, 판매가, 배송비, 수수료 설정과 거래 상태는 현재 이용자의 브라우저 로컬 저장소에 저장됩니다. 리셀리 자체 서버로 이 입력값을 전송하는 계정·동기화 기능은 제공하지 않습니다. 브라우저 데이터 삭제, 기기 변경 또는 브라우저 설정에 따라 기록이 없어질 수 있으므로 필요한 기록은 CSV 파일로 백업하세요.

2. CSV 내보내기

이용자가 CSV 내보내기를 선택하면 거래 내역 파일이 이용자의 기기에 다운로드됩니다. 해당 파일을 어디에 보관하거나 누구와 공유할지는 이용자가 관리해야 합니다.

3. 광고 및 쿠키

현재 리셀리 자체 페이지에는 Google AdSense 광고 코드나 별도의 웹 분석 도구가 포함되어 있지 않습니다. 추후 광고·분석 도구가 도입되면 이 안내를 실제 사용 방식에 맞게 업데이트하고, 해당 제공자가 쿠키·광고 식별자·IP 주소 등 정보를 처리할 수 있음을 고지할 예정입니다. Google 광고가 도입되는 경우 Google의 쿠키 및 개인정보 안내도 함께 확인할 수 있도록 링크를 제공합니다.

4. 외부 서비스

웹사이트는 GitHub Pages를 통해 호스팅되며, 문의 링크는 GitHub 이슈 페이지로 연결됩니다. 외부 서비스를 이용할 때는 해당 서비스의 정책과 이용 조건이 적용됩니다. 리셀리 이슈 페이지에 비밀번호, 거래 상대방 연락처 등 민감한 정보를 게시하지 마세요.

5. 이용자가 선택할 수 있는 조치

  • 사이트의 '수수료 설정' 탭에서 '모든 데이터 삭제'를 사용하면 이 브라우저에 저장된 상품 기록과 수수료 설정을 삭제할 수 있습니다.
  • 필요한 거래 기록은 삭제 전에 CSV로 백업하세요.
  • 브라우저 설정에서 사이트 데이터를 지우면 리셀리의 저장 기록도 삭제될 수 있습니다.

6. 안내 변경

기능이나 외부 도구가 변경되면 이 문서를 실제 운영 방식에 맞게 수정합니다. 광고 승인을 받고 광고 코드를 추가하기 전에는 광고 제공자, 쿠키, 동의 절차와 관련된 고지를 다시 확인해야 합니다.

7. 문의

개인정보 안내 또는 사이트 기능에 대한 문의는 GitHub 이슈 페이지를 통해 전달할 수 있습니다. 공개 이슈에는 개인정보를 작성하지 마세요.
